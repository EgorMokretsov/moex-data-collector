# MOEX Data Collector

Учебный проект: ИС №1 для сбора архивов OrderLog Московской биржи
и импорта реальных биржевых данных в PostgreSQL.

## Что реализовано

Ручной запрос архива по рынку, дате и типу A/B: программа читает реальный
каталог MOEX, скачивает найденный файл и распаковывает ZIP/7z. Поддерживаются
Equities, Bonds, Currencies и Derivatives Market, включая кириллические А/В
в именах. Загрузка и распаковка выполняются на диск потоками.

Временный файл `.part` получает окончательное имя только после полной загрузки
и проверки целостности архива. При сетевых ошибках, повреждении или прерывании
незавершённый результат удаляется. Повторный запрос проверяет существующий
архив и использует его без повторного скачивания. Повреждённый локальный
архив скачивается заново; старый заменяется только после успешной проверки.

Распаковка выполняется во временный каталог. Проверяются CRC, пути, типы
файлов и свободное место. Ссылки, пути вне каталога распаковки, зашифрованные
архивы и конфликтующие имена отклоняются. Готовый каталог публикуется только
после успешной распаковки. Файл `.moex-extraction.json` хранит SHA-256 архива
и распакованных файлов: повторный запрос проверяет их и пропускает распаковку.
Если пользователь изменил файлы, программа сохраняет их и просит выбрать
другой `--extracted-dir`.

Парсинг содержимого, таблицы и импорт в PostgreSQL, автоматическое расписание
пока не реализованы. Для загрузки и распаковки PostgreSQL не нужен.

## Быстрый старт в Windows / PowerShell

Нужен Python 3.12 или новее, доступный командой `python`.

```powershell
python --version
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
.\.venv\Scripts\python.exe -m app --help
.\.venv\Scripts\python.exe -m app markets
.\.venv\Scripts\python.exe -m pytest
```

Активация окружения не требуется: команды используют его Python напрямую.
После установки также доступна команда `.\.venv\Scripts\moex-collector.exe`.
Альтернативный запуск из корня: `.\.venv\Scripts\python.exe main.py --help`.

Если установленный `python` старее 3.12, сначала установите Python 3.12+
и создайте окружение с ним. В текущей рабочей папке окружение `.venv`
уже подготовлено на Python 3.12; команды ниже можно выполнять напрямую.

## HTTPS и сертификат MOEX

При проверке 24.10.2026 сервер MOEX предъявлял сертификат НУЦ Минцифры,
которому стандартный набор `certifi` не доверяет. Описание перехода и
официальный источник сертификатов приведены в
[инструкции MOEX](https://www.moex.com/kak-sohranit-dostup-k-servisam-birzhi).

Для проекта можно использовать отдельный PEM-файл, не меняя хранилище Windows:

```powershell
New-Item -ItemType Directory -Force certs | Out-Null
Invoke-WebRequest -Uri "https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt" -OutFile certs/moex-ca.pem
$env:MOEX_CA_BUNDLE = "certs/moex-ca.pem"
```

Переменная действует в текущем PowerShell. Для следующих запусков добавьте
`MOEX_CA_BUNDLE=certs/moex-ca.pem` в локальный `.env`. В текущей рабочей папке
этот файл и настройка уже подготовлены. Файлы сертификатов и `.env`
исключены из Git. Сертификат применяется к HTTP-сессии коллектора;
проверка цепочки, имени сервера и срока действия остаётся включённой.
Также поддерживаются `--ca-bundle PATH` и стандартный `REQUESTS_CA_BUNDLE`.

## Ручная загрузка

Посмотреть доступные архивы валютного рынка:

```powershell
.\.venv\Scripts\python.exe -m app archives --market currencies
```

Скачать архив B за 01.10.2024 и распаковать:

```powershell
.\.venv\Scripts\python.exe -m app download --market currencies --date 2024-10-01 --type B
```

Результат для этого запроса:

```text
downloads/currencies/OrderLog20241001_B.zip
extracted/currencies/OrderLog20241001_B/OrderLog20241001.txt
```

Другие варианты:

```powershell
# Список облигаций с фильтром по типу и дате
.\.venv\Scripts\python.exe -m app archives --market bonds --date 2024-10-01 --type A

# Скачать 7z срочного рынка без распаковки
.\.venv\Scripts\python.exe -m app download --market derivatives --date 2024-10-01 --type B --download-only

# Выбрать свои папки для архивов и распакованных файлов
.\.venv\Scripts\python.exe -m app download --market currencies --date 2024-10-01 --type B --downloads-dir D:/MOEX/downloads --extracted-dir D:/MOEX/extracted
```

Рынки: `equities`, `bonds`, `currencies`, `derivatives`. Дата — `YYYY-MM-DD`.
Команда `archives` показывает только ссылки из каталога MOEX. Если дата
отсутствует, `download` сообщает об этом и показывает доступные даты.
Наличие файлов за каждый торговый день не предполагается.

В `.env` можно задать `DOWNLOADS_DIR`, `EXTRACTED_DIR`, `LOG_LEVEL` и
`MOEX_CA_BUNDLE`. Относительные пути из `.env` считаются от корня проекта;
пути из аргументов CLI — от текущей папки. Тайм-ауты: 10 секунд на подключение
и 60 секунд на ожидание данных. При временных HTTP-ошибках выполняются
повторные запросы. После обрыва тела файла повторный запуск начинает загрузку
заново; докачка по HTTP Range пока не реализована.

## Структура

```text
app/
  cli.py          # Команды markets, archives, download
  config.py       # Настройки из окружения и .env
  markets.py      # Четыре рынка и адреса каталогов
  http.py         # HTTP-сессия, повторы запросов и TLS
  errors.py       # Ожидаемые ошибки операций
  database.py     # Фабрика подключения SQLAlchemy
  models.py       # Базовый класс будущих ORM-моделей
  discovery.py    # Поиск архивов в реальном каталоге MOEX
  downloader.py   # Потоковое скачивание и проверка целостности
  extractor.py    # Безопасная распаковка ZIP/7z
  parser.py       # Чтение и нормализация — запланированы
  importer.py     # Пакетный импорт и история — запланированы
  scheduler.py    # Проверка новых архивов — запланирована
downloads/        # Подкаталоги четырёх рынков
extracted/        # Распакованные файлы
logs/             # Локальные журналы
certs/            # Локальные PEM-сертификаты, исключены из Git
tests/            # Конфигурация, HTTP-загрузка, ZIP/7z и CLI
docs/roadmap.md   # Следующие этапы
main.py           # Дополнительная точка входа
pyproject.toml    # Метаданные, зависимости и настройки pytest
requirements.txt # Установка проекта с зависимостями для разработки
.env.example     # Пример локальных настроек
```

## Библиотеки

- `requests` и `beautifulsoup4` — HTTPS-запросы и разбор каталогов MOEX.
- `py7zr` — архивы 7z; для ZIP используется стандартный `zipfile`.
- `SQLAlchemy` и `psycopg` — модели, соединения и работа с PostgreSQL.
- `python-dotenv` — чтение локального `.env`.
- `pytest` — проверки поведения приложения.

Зависимости объявлены в `pyproject.toml`. `requirements.txt` устанавливает
этот же проект с набором `dev`; отдельный список версий не дублируется.

## Git и локальные данные

`.env`, виртуальное окружение, скачанные и распакованные данные, журналы
исключены через `.gitignore`. В Git сохраняются только `.gitkeep` для
пустых рабочих каталогов. Пароли не добавляйте в исходный код.

Проверены каталоги всех четырёх рынков и реальная загрузка Currencies B
за 01.10.2024: архив 4 476 171 байт, внутри `OrderLog20241001.txt`
размером 36 389 941 байт. Проверен и повторный запрос без новой загрузки.
Автотесты используют явно синтетические технические файлы и локальный
HTTP-сервер; они не обращаются к MOEX. ZIP и 7z проверяются отдельно.
