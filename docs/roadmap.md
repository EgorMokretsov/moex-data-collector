# План разработки ИС №1

## Выполнено

- Проверены HTTPS-каталоги всех четырёх рынков MOEX.
- Реализован просмотр архивов и ручная загрузка по рынку, дате и типу A/B.
- Реализованы потоковое скачивание, проверка целостности, распаковка ZIP/7z
  и повторное использование проверенных локальных файлов.
- Выполнена реальная загрузка и распаковка Currencies B за 01.10.2024.
- Добавлены проверки сетевых ошибок, повреждённых архивов и безопасных путей.

## Следующие этапы (пока не реализуются)

1. Исследовать структуру и поля распакованных файлов, отличия рынков и A/B.
2. Уточнить схему PostgreSQL по реальным полям, добавить модели и миграции.
3. Реализовать парсеры и пакетный импорт с защитой от дублей.
4. Проверить повторные запуски, ошибки и прерывания импорта.
5. Добавить настройку расписания и журналирование импортов.

Предварительные таблицы — `archives` и `market_events`. Их поля пока
не утверждены. Нужно сохранять исходные поля и связь каждой записи
с архивом, внутренним файлом и номером строки.

REST API, ИС №2, Telegram-бот, Excel-отчёты и веб-интерфейс находятся
за рамками текущего этапа.
